# Política de Segurança

## Versões suportadas

Enquanto o LionTray estiver na série 1.x, correções de segurança serão direcionadas à versão mais recente publicada.

## Relatando uma vulnerabilidade

Se o problema puder expor dados, executar código inesperado, contornar permissões ou tiver outro impacto de segurança, **não publique detalhes sensíveis em um Issue público**.

Prefira usar o recurso **Report a vulnerability / Security Advisories** do GitHub quando ele estiver disponível neste repositório. Se essa opção não aparecer, abra um Issue curto informando apenas que você precisa reportar um problema de segurança em privado, sem incluir exploração, segredos ou dados pessoais.

Inclua, em canal privado quando possível:

- versão do LionTray;
- versão do GNOME Shell e distribuição;
- descrição do impacto;
- passos mínimos para reproduzir;
- logs relevantes sem dados sensíveis;
- sugestão de correção, se houver.

Relatos de boa-fé serão tratados com prioridade e com crédito ao pesquisador, salvo pedido em contrário.
