# Código de Conduta

O LionTray quer manter um ambiente técnico, direto e respeitoso para quem usa, relata problemas ou contribui.

Esperamos que participantes:

- discutam ideias e código sem ataques pessoais;
- tratem dúvidas e erros de boa-fé;
- evitem assédio, discriminação, ameaças e exposição de dados pessoais;
- mantenham Issues e Pull Requests relacionados ao projeto;
- respeitem decisões de moderação e revisão mesmo quando houver discordância.

Comportamentos que tornem a colaboração hostil podem resultar em edição, ocultação ou encerramento de conteúdo e, em casos graves ou repetidos, bloqueio de participação no projeto.

Se houver um problema de conduta que não seja apropriado discutir publicamente, entre em contato com o mantenedor pelo perfil GitHub `@Pianisuto` sem publicar informações sensíveis.
